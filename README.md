# Personal Portfolio Website - A mini project for Prodigy Infotech

Portfolio is a personal website that showcases projects, skills, and achievements.
It is built using HTML, CSS, and JavaScript, and designed to provide a professional online presence.

## Project Overview

### This project includes:

* Home section with introduction and profile
* Projects section showcasing mini web projects
* Skills and experience section

## Technologies Used

* Frontend: HTML5, CSS3

* Scripting: JavaScript

## How to Run

1. Clone or download the repository:

    git clone https://github.com/ShriBangera/Portfolio.git


2. Open index.html in a web browser.

3. Explore the portfolio and navigate through the sections.
